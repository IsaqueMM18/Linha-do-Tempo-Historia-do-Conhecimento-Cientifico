# Linha-do-Tempo---Hist-ria-do-Conhecimento-Cient-fico
Linha do tempo interativa sobre a História do Conhecimento Científico, da Antiguidade à contemporaneidade, apresentando 10 marcos históricos, suas contribuições e contextos. Desenvolvida com TimelineJS, HTML, CSS e JavaScript, com referências acadêmicas e publicação via GitHub Pages.
